Data I've moved, and how I proved it

Each of these took data from one place to another. The part that matters is the last line.

  1. A group of more than 100 companies, consolidated

    From

    Financial data in each company's own systems, which kept running

    To

    One central warehouse and consolidation engine

    SQL Server change data capture and agents over linked servers kept both sides in sync on an ongoing basis.

    Reconciliation checks before any figure reached the engine. Data-gathering time fell by 70%.

  2. Insurance data integration

    From

    Separate systems at three insurers, including Iran's largest

    To

    Integrated, consolidated data each business could rely on

    Built on SQL Server with change data capture. I managed the projects and worked hands-on where they needed it.

    Delivered in a regulated industry, where figures that don't reconcile aren't a small problem.

  3. Wheat genomics, migrated to new gene models

    From

    RefSeq v1.1 gene models

    To

    RefSeq v2.1 gene models

    Python identifier mapping between versions, plus a bridge between wheat and Arabidopsis homologs using OMA orthologous groups.

    Validated against an approved reference output before anyone relied on it.

  4. The KnetMiner knowledge graph

    From

    More than ten separate biological data sources

    To

    One Neo4j and RDF graph of millions of nodes

    ETL pipelines on AWS mapped each source to a shared, ontology-based domain model.

    Used by crop researchers for gene discovery.

  5. Executive reporting at Rothamsted Research

    From

    Manual collection of finance, HR, legal and funding data

    To

    Automated reporting on Microsoft Fabric

    Python, SQL and Data Factory pipelines into Power BI semantic models, with KPI definitions agreed across departments.

    One analysis linked media coverage to funding. The investment that followed helped lift funds secured by 66%.

How I use AI

I use AI coding agents every day, but I don't trust any single one. Claude Code and Gemini Antigravity check each other's work on our HPC cluster, and when they disagree, that's usually where I need to look.

I also built an agent that runs and verifies our data pipeline. Nothing it produces gets merged until I've reviewed it.

At KnetMiner I work on an agentic tool built on a locally hosted Llama model. It answers researchers' questions by searching the knowledge graphs they've already built, and it can start from a biological concept and build a new graph around it.
